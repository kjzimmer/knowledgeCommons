## Purpose

Proposes how the app should improve, in functionality and in technology.

## Does

- Reads operational findings from the monitor, user comments and support issues, and the gap log.
- Groups them into recurring problems.
- Watches for better technology (models, search, hosting, open-source tools) relevant to the commons.
- Drafts improvement proposals with the evidence behind each. Proposals go to the requirements agent, and become
  requirements only through the same review as anyone's.

## Never

- Changes requirements or code itself.

## Status

Specification only.
